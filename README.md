# 💻 Lógica de Programação em C

Exercícios e testes desenvolvidos em **linguagem C** no **Visual Studio Code**, com o objetivo de reforçar os fundamentos da **lógica de programação** — praticando desde as estruturas básicas até o uso de vetores, matrizes e funções.

---

## 🎯 Objetivo

Este repositório reúne **exercícios e testes práticos** criados durante meus estudos de linguagem C.  
O foco é aplicar, de forma progressiva, os principais conceitos da lógica de programação e aprimorar o raciocínio lógico por meio de exemplos reais.

---

## 📚 Conceitos praticados

- Estruturas **sequenciais**
- Estruturas **condicionais**
- Estruturas **repetitivas**
- **Vetores** e **matrizes**
- **Funções**
- Entrada e saída de dados pelo terminal

---

## 🧰 Ferramentas utilizadas

- Linguagem: **C**
- IDE/Editor: **Visual Studio Code**
- Compilador: **GCC (via extensão Code Runner / MinGW)**

---
